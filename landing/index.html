El proyecto

Qué es Booqi

Booqi es un sistema de gestión y reserva de entradas para eventos. Cubre el recorrido completo de quien compra y de quien organiza, con cada dominio en su propio servicio y su propia base de datos.

  • Catálogo de eventos

    Búsqueda y filtros por categoría, fecha y precio, con paginación en la URL.

  • Carrito y checkout

    Cantidades acotadas al stock, total al céntimo y resultado de pago por línea.

  • Pagos simulados

    payment-service aprueba o rechaza, descuenta stock y confirma o cancela la reserva.

  • Entradas en PDF con QR

    Una página por entrada, generada en el navegador y descargable al instante.

  • Mis reservas

    Historial agrupado por evento, con detalle y cancelación con confirmación.

  • Panel de administración

    Usuarios, eventos y ventas, con métricas e informe de ventas en PDF.

Cómo está hecho

Arquitectura de microservicios

nginx sirve el frontend y hace de proxy de /api/v1 hacia cuatro servicios Spring Boot. Cada servicio es dueño de su esquema en MySQL (database per service) y expone una API REST con errores RFC 9457.

  • booking-service consulta a user-service y a event-service.
  • payment-service descuenta stock y confirma o cancela la reserva.
  • Documentación OpenAPI y Swagger UI en cada servicio.

En tu máquina

Ejecútalo en local

Solo necesitas git y Docker (o Podman) con Compose v2. Ejecuta los comandos desde la raíz del repositorio.

  1. Clona el repositorio

    git clone https://github.com/RenzoRamosDEV/Booqui-TFG.git
cd Booqui-TFG

  2. Crea la configuración

    Copia el fichero de ejemplo y cambia las contraseñas de ejemplo.

    cp infra/.env.example infra/.env

  3. Levanta el stack

    La primera vez construye las imágenes; el stack tarda unos 2–3 minutos en estar sano.

    docker compose -f infra/docker/docker-compose.yml -f infra/docker/docker-compose.override.yml --env-file infra/.env up -d --build

  4. Abre la app

    La app queda en http://localhost. Si tu Docker o Podman rootless no puede publicar el puerto 80, pon BOOQI_FRONTEND_PORT=8088 en infra/.env y abre http://localhost:8088.
